# Певческая башня

Адаптивный сайт для согласования с клиентом.

**[Открыть сайт](https://spice12cake3-lang.github.io/pevcheskaya-tower/)**

Главная, меню, страницы пространств, афиша, раздел для турагентств и карьера. Фотографии, шрифты и PDF-меню хранятся в проекте. Изображения отдаются в адаптивных размерах WebP и JPEG; шрифты — в WOFF2. Первый снимок загружается приоритетно, изображения ниже — по мере прокрутки. Прелоадер первого экрана имеет ограничение по времени и не ждёт загрузки всего сайта.

Формы заявок пока демонстрационные: проверяют заполнение и согласие, но не отправляют данные. Внешний виджет бронирования номера ещё не подключён.

Видео на главной расположено после пространств и показывается при ширине от 900 px и точном указателе с наведением (мышь или трекпад). В MP4 Full HD удалена звуковая дорожка, используются H.264 и fast start. При появлении блока на экране ролик запускается автоматически без звука; за пределами экрана и в скрытой вкладке ставится на паузу. На мобильных устройствах файл и обложка не загружаются. Системная настройка уменьшения движения отключает автозапуск; ручное управление остаётся доступным. Файлы находятся в `dist/assets/video/`.

Для загрузки через веб-интерфейс GitHub исходные данные ролика разбиты на части в `src/video-parts/`. `build.py` автоматически собирает MP4 по `src/video-asset.json` и проверяет его SHA-256. Готовый ролик попадает в `dist/assets/video/`; дополнительные инструменты для обычной сборки не нужны.

## Локальный запуск

Требуется Python 3, дополнительные пакеты не нужны.

```sh
python3 build.py
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173/.

## Структура

- `src/` — шаблоны, стили, скрипты и данные.
- `dist/` — готовый сайт и его изображения, шрифты, PDF.
- `src/prepare_images.py` — подготовка WebP-вариантов при замене фотографий (требуется Pillow); результат фиксируется в `src/image-manifest.json` и `dist/assets/optimized/`. Обычная сборка не требует Pillow.
- `src/prepare-menu-previews.py` — подготовка постраничных WebP-версий меню (требуются Pillow и pypdfium2). После замены PDF запустить скрипт и `build.py`. Просмотрщик загружает текущую страницу и заранее готовит следующую; исходные PDF сохраняются. Данные страниц находятся в `src/menu-previews.json`, изображения — в `dist/assets/menu-pages/`. Обычная сборка не требует дополнительных пакетов.
- `build.py` — сборка всех страниц.
- `tilda-t123.html` — дополнительный HTML-фрагмент главной страницы.
- `.github/workflows/deploy.yml` — сборка и публикация в GitHub Pages при изменениях в `main`.

Все права на материалы сайта сохраняются за их правообладателями.

Новые фотографии апартаментов, Сочи, Одессы, караоке, Индии и магазина сохраняются без повторного JPEG-сжатия. Их адаптивные WebP-варианты кодируются без потерь; если полноразмерный WebP тяжелее исходника, используется исходный JPEG.

Фотография детской зоны в карточке главной страницы хранится отдельно в assets/kids-card.jpg; фотографии внутри детской страницы остаются прежними.

В галереях страниц пространств всегда три миниатюры: при обновлении фотографий состав подбирается с сохранением этого количества.
